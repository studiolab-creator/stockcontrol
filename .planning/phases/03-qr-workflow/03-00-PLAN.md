  <action>
Append the following block to the END of `src/app/globals.css`. Do not modify any existing rules:

```css
/* ── Print layout for QR sheet (Phase 3) ─────────────────────────────────── */
@media print {
  @page {
    size: A4;
    margin: 10mm;
  }
}
```

This sets A4 paper size and 10mm margins per D-12. The Tailwind `print:hidden` and `print:block` variants are already built-in to Tailwind v4 — no @custom-variant is needed. This @page rule is the only addition required.

Do NOT add `body > * { display: none; }` or any rule that manipulates `<body>` or `<html>` display during print — this causes React hydration errors (RESEARCH.md Pitfall 7). Hiding of app chrome is done via `print:hidden` on the SidebarProvider wrapper in QrManagementClient.
  </action>
